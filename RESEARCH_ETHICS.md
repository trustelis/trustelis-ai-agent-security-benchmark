# Defensive research and ethics

All demonstrations run in an isolated synthetic scenario set. No live customer infrastructure or third-party services are targeted. The optional OpenAI integration classifies text and never grants the model network tools, operating system access, API admin powers or execution capabilities.

Prompt-injection examples are minimal synthetic messages included to assess whether a model or reference evaluator respects the separation between untrusted content and authority. Do not extend this project with real exploit targets, exfiltration payloads or unauthorized vulnerability scans.

Only publish anonymized, synthetic examples and aggregate reproducible results. Avoid sharing organization data, personal data, proprietary implementations and nonpublic vulnerability details. Research outputs should include method, sample size, model configuration, evaluation limitations and source provenance.
