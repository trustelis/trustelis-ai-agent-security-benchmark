# Roadmap (proposed; not completed)

## v0.1 — Synthetic reference and decision classifier (implemented)

- 26 fully synthetic Finance, IT Operations, and HR scenarios.
- Deterministic example policy evaluator with tenant, role and approval checks.
- Offline model-decision scoring and bounded opt-in OpenAI classification adapter.
- Reproducible tests, documentation, security boundaries and Apache-2.0 license.

## v0.2 — Evidence and quality improvements (planned)

- Cross-model result comparisons with explicit API cost/usage provenance.
- Security category reporting, per-run reproducibility metadata, and confidence intervals where justified.
- Optional agent tool-proposal *simulation* and event traces, without executing sensitive commands.
- Expanded evaluation of injection handling and approval bypass attempts.

## v0.3 — Wider research corpus (planned)

- Curated 60 core scenarios, then ~200 variants across business contexts and authorization modes.
- Independent review of golden labels and expected policy outcomes.
- Community contributions, additional provider adapters if feasible.

## v1.0 — Research-grade release (aspirational)

- Stable schema and versioned datasets.
- Documented, reproducible comparisons with real model outputs and uncertainty disclosures.
- Public non-sensitive technical report and benchmarking methodology.

The roadmap contains **aspirations**, not commitments about model access, API credits, grant funding, adoption, or results.
